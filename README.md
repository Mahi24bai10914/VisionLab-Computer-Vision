# VisionLab - Interactive Computer Vision Image Analysis System

## Overview

VisionLab is an interactive Computer Vision application developed using Python and OpenCV. It allows users to upload images and apply different image processing and computer vision techniques through a simple web interface.

## Features

- Image preprocessing
- Grayscale conversion
- Gaussian filtering
- Histogram equalization
- Intensity histogram visualization
- Canny edge detection
- Harris corner detection
- Binary thresholding
- Otsu thresholding
- Adaptive thresholding
- SIFT feature matching
- Image comparison

## Technologies Used

- Python
- OpenCV
- NumPy
- Pillow
- Matplotlib
- Streamlit
